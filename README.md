# Omizu Hinaki Portfolio

Omizu Hinakiのポートフォリオサイトです。プロフィール、スキル、制作実績、問い合わせフォームを掲載しています。

## Pages

- `index.html`: トップページ、資格・実績、スキル、注目作品、問い合わせ
- `works.html`: 制作実績一覧
- `thanks.html`: フォーム送信後のサンクスページ
